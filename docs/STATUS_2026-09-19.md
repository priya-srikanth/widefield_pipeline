## 0. THE ONE-PARAGRAPH VERSION

The day started as "is there less cue- or lick-evoked neurovascular coupling after stroke" and became
an audit of what 415 nm is in this preparation. **The honest headline is a negative one: no amplitude
and no map can separate "415 carries scaled calcium" from "415 carries haemodynamics that scale with
calcium", because NVC is itself signal-proportional.** Along the way four of my own claims were
retired by Priya and three real analysis bugs were found and fixed. A second thread — why engagement
falls after the stroke — produced the day's most usable behavioural result.

## 1. RESULTS YOU CAN CITE

### 415/470 coupling across epochs (`channel_position_maps --epochs`, 96 sessions)

Paired animals→sessions bootstrap of the difference from pre, per-trial pre-cue baselines:

| arm | epoch | Δ coupling gain | Δ spatial match |
|---|---|---|---|
| cue | subacute | **−0.031 [−0.058, −0.005]** | −0.024 [−0.197, +0.129] |
| lick | subacute | **−0.038 [−0.072, −0.006]** | −0.032 [−0.207, +0.120] |

All acute and subacute changes negative; spatial match moves nowhere. **No increase. A weak hint of
a small subacute decrease, amplitude only.** Two of twelve uncorrected tests — suggestive, not
established.

### Position-specific deficit vs global state (`engagement_decomposition`, all animals)

Acute, median first-lick latency: **near-ipsi 0.186 s** (pre 0.147) against **far-contra 0.850 s**
(pre 0.261). Hit rate 0.686 against 0.033. **In the same sessions with the same tongue the animal is
near-normal at near spouts and destroyed at far-contra** — so the far deficit is not a global state.
Chronic recovers essentially completely on both.

Near spouts by session quintile, acute: **0.972 / 0.937 / 0.792 / 0.457 / 0.282**. Acute Q1 is
indistinguishable from pre's 0.980 — **the near-spout deficit is entirely a within-session decline,
not a baseline impairment.** Malaise should have depressed Q1.

### Time engaged, censored (`quit_point`)

| epoch | frac of session engaged | censored |
|---|---|---|
| pre | 0.96 [0.92, 1.00] | 0.66 |
| acute | 0.82 [0.73, 0.92] | 0.25 |
| subacute | 0.84 [0.72, 0.96] | 0.28 |
| chronic | 0.95 [0.84, 1.00] | 0.78 |

Session durations are 106–115 min in every epoch, so this is not the cap. CIs overlap — suggestive.
**Chronic is 78% censored and is the least trustworthy cell.**

### Within-session 415 drift (113 sessions)

415 falls **−11.6%** per session against 470's **−4.78%**, further in **111/113**. Roughly a constant
extra −7.3% (slope 0.75 on the 470 drop). Partial correlation says TIME-locked, not behaviour-locked:
r(ratio, time) −0.79 to −0.87, partial r(ratio, lick | time) +0.15 / +0.10 / −0.24. **Bleaching-like,
not haemoglobin.**

## 2. THINGS THAT ARE **NOT** RESULTS — do not quote these

- **Quit DETECTION RATE (0.34 pre / 0.75 acute).** Confounded by recording policy: pre-stroke ran
  "up to 2 hrs or until they stopped licking", so a pre session often ended AT the quit and leaves no
  tail for a gate needing a sustained non-recovering run. Durations show it: pre spans 74–167 min,
  acute 100–126. Use `frac_engaged` instead.
- **Anything from `channel_position_maps` before the per-trial baseline went in.** The unbaselined
  lick gain read 0.575 / 0.700 / 0.800 — double, and RISING where the truth is flat-to-falling. An
  apparent acute increase and a real small subacute decrease is a REVERSAL, not a rescaling.
- **The globalness decomposition** (excess vascular globalness ≈ 0, `DECISIONS` §5 of the 415 day).
  Its CORRELATION columns are unaffected by a uniform offset and should survive; its AMPLITUDE
  columns predate the baseline fix and must not be quoted. **Needs a re-run.**
- **`r_hit_licks` in `engagement_decomposition`.** `cum_licks` is largely a running sum of past
  SUCCESSES, so it is endogenous — the positive partial (+0.28 to +0.47) is the diagnostic that the
  predictor is broken, not a finding. Collinearity with time is 0.965–0.993 anyway.
- **`within_drop` wherever the early hit rate is near zero.** Floor effect; a `within_drop_valid`
  flag now marks these.

## 5. PITFALLS THAT BIT TODAY — read before touching this code

- **A weak discriminator is worse than none, because it is only wrong where it matters.** My
  "derive the channel rather than assume it" heuristic was a coin flip on PS93_0606 (margin 0.030)
  and landed wrong, swapping 415 and 470. It did not look broken — it looked like a finding, and
  PS93 already had two other flags so a narrative was waiting. **The answer was in the config all
  along** (`local_wfield_summary.json`). See `hemo_variants.functional_channel`.
- **`FUNC = 1` is the COHORT default and `PS92_0828` is 0.** Production honours it end to end; ten
  analysis modules that sliced RAW `SVT` by the constant did not. All fixed — but check any new code.
- **Colour limits must be computed inside the brain mask.** `U_atlas` has extreme values at the
  registered edge; an all-pixel 99th percentile inflated five of six rows by up to 4.8× and left the
  sixth alone, which reads as one position with a huge response.
- **Averaging step functions with variable step times manufactures a ramp.** Any session-normalised
  within-session curve has this exposure. Align to each session's own quit point.
- **Right-censoring bounds from BELOW.** I wrote "upper bound" and Priya corrected it. Pre-stroke is
  the most censored, so measured pre understates true pre — which makes a post-stroke shortfall
  conservative and a post-stroke excess meaningless.
- **Never pipe a run whose exit code you intend to trust.** `... | tail -20` reports tail's exit
  code; `grep -c` exits 1 on zero matches. Both misreported runs today. Redirect to a file and read
  the file.
- **Two heredocs in one bash command fail**, and perl `-0pi` substitutions silently no-op when the
  file has CRLF and the pattern has `\n`. Check that an edit landed before building on it.

## 6. WHAT PRIYA CORRECTED, kept because each was load-bearing

1. **Spatial correlation is what NVC predicts** — so it cannot be the bleed-through discriminator.
2. **Do not mask the coefficient fit** — the trial window holds real trial-aligned haemodynamics,
   which is exactly what `T` must estimate. This killed both the masking and IRLS proposals.
3. **Increased non-position-specific coupling would itself be interesting** — subtracting globalness
   as a nuisance assumed the answer.
4. **You cannot compare raw counts across two independently-set LEDs** — retired my autofluorescence
   argument.
5. **Anticipatory licking is itself a lick**, so fatigue or a motor deficit degrades it too. Confirmed
   in the data: pre-stroke anticipation halves from near to far while hit rate stays flat.
6. **Session-termination policy changed between pre and post** — invalidated the quit detection rate.
7. **Right-censoring is a lower bound**, not an upper one.
