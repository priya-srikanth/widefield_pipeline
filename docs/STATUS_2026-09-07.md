## 1. Both engagement gates start at the run that trips them

**What changed.** `reference_engagement` (behaviour) and `engagement_gate` (imaging) both marked
disengagement where the trailing reference response rate CROSSED `MIN_RATE`, which takes about eight
reference misses to accumulate. Every one of those misses was scored **working** — an *engaged*
failure — although the animal had already stopped. Onset is now the trial after the last reference
RESPONSE: the first miss of the run that trips the gate.

**Why that phrasing.** "Last demonstrably engaged" is a fact about the animal. "Where a rolling
average happened to cross" is an artefact of `WINDOW` and `MIN_RATE` and would move if either
constant were retuned.

**Measured cost.**

| | |
|---|---|
| behaviour: trials moving engaged → disengaged | 335 (8.9% of the working class) |
| behaviour: mean engaged hit rate | 0.8187 → **0.8313** (+1.26 pp) |
| imaging: `poststroke_miss_working` → `poststroke_stopped` | 408 of 3797 (10.7%) |
| worst single session (PS94 0903) | working 65 → 16, stopped 80 → 129 |

**Imaging is a RELABEL, not an exclusion** — both classes are analysed downstream, so no trial
leaves the analysis. The frozen decoder's TRAINING is untouched either way: it is pre-stroke LICK
trials only (21,254 of them), and no-lick trials never enter it.

### What this does and does not touch — check this before assuming a figure moved

**The gate only affects analyses that use the "working" class.** Everything else splits
engaged/no-lick by *a lick detected within `max_rt`* (3.5 s), which is a different criterion:

| module | gate refs | splits on |
|---|---|---|
| `locanmf_frozen_decoder` | **0** | lick / `max_rt` |
| `locanmf_position_decoder` | **0** | lick / `max_rt` |
| `locanmf_rsa` | **0** | lick / `max_rt` |
| `locanmf_cross_mouse` | **0** | lick / `max_rt` |
| `joint_locanmf` | **0** | — |

So deck slides **4–24** (per-animal within-day decoders/encoders), **38–78** (frozen cross-day,
joint-basis health) and the RSA slides **do not move**. What moves is section G, the `grant_figures`
"working" variants, section I, and the behaviour figures.

**No `CACHE_VERSION` bump was needed, and this was checked rather than assumed.** All eight modules
that write `session_cache` contain zero references to the engagement split — they cache features and
pre-stroke-trained models. The one gate-dependent artefact on disk, `coding_direction.json`, is
regenerated nightly by `position_coding_directions`. The bootstrap caches key on input BYTES, so
they invalidate themselves — **which means the first run after this change pays full bootstrap
cost.**

`camera_nightly` calls `spout_behavior.run(date, …)` for ONE date, and epoch figures 1b/1c read
per-session `position_metrics.csv`. Without a cohort pass the pooled figure mixes one new-gate
session with 43 old-gate ones — silently, because the file format is identical.

```

```

## 2. Example clips (`behavior_clips`, `behavior_clip_deck`)

Cue-aligned cam4 clips for a lab meeting: **1 s pre-cue → 3.5 s post-cue at 0.25x**, ENL / Cue /
Response named on every frame, per position and per trial class.

**Built:** 2,903 clips, 8.5 GB, all 44 sessions, ~101 min. Plus one deck per animal (~316–436 MB).

| decision | why |
|---|---|
| **cam4** | the front-facing camera (Priya) |
| **3.5 s post-cue, not 3.0** | `timing.response_window` is 3500 ms in every gui_config.json; 3 s ends before the window the animal is scored on |
| **frames from the alignment template** | `cue_s` IS the DAQ cue rising edge (checked: 0.0000 s over 600 trials); the affine maps DAQ→camera at ~1.2 ms, a third of one frame at 250 fps |
| **skip on bad template** | never cut with a guessed offset — that flag is what caught the 8/18 folder swap |
| **engagement RECOMPUTED per clip** | the persisted `engaged` column may predate the backdating |
| **`NofM` in the filename** | `far_R_working_1of1` vs `far_R_success_5of108`: a 1-in-109 outlier and a representative sample otherwise produce indistinguishable files |
| **flat cap 5 on disk, curation in the DECK** | the library answers questions; the deck presents them. Curating at generation means re-encoding video whenever the presentation changes its mind |
| **240 px embeds in the deck** | 480 px would put a per-animal deck at ~2.1 GB |
| **square cells** | cam4 is 680x680; a 4.05x2.75in placeholder stretched every frame 1.47x, which on a mouse's face reads as anatomy |
| **fixed position slots** | packing shown clips top-left moves a position between slides, and the reader compares different spouts in the same place without noticing |
| **absence slides** | PS92 09-04 hit 378 of 378, so it has no working and no stopped trials; a missing slide reads as a rendering gap rather than as the result |

Deck caps: success 2, stopped 2, working **5 at far middle / far contra** and 2 elsewhere.

### The epoch folder is a claim, and it goes stale

`chronic_from` is derived from behaviour and republished nightly (the other window, `596cf33`), so a
boundary that shifts restales every clip cut before it. Three PS92 sessions (0828, 0901, 0904) were
sitting under `subacute/` after that animal's chronic boundary landed. **Two guards, because one is
not enough:** `refile_stale_epochs` moves the folders before each cut, and the deck DERIVES its
label from `epoch_of` rather than the directory, so the slide is right even if the re-file has not
run. 44 filed correctly, 0 misfiled.

## Traps this session paid for

- **Heredocs through Git Bash halve `\n` escapes.** Four failures today alone, including one that
  silently wrote nothing. Write patch scripts to a FILE (Write tool) and run them, or use `chr(10)`.
- **A blanket text match is not a rule.** "no-lick" matches "no-lick generalization"; ordering the
  specific pattern first is the difference between 17 correct labels and 30 with 9 wrong.
- **Variable shadowing in a loop.** `made = min(avail, per_cell)` collided with the `made` clip
  counter and produced filenames counting 5of11, 6of11, 7of11 — a running total wearing the name of
  a constant. Caught only by looking at the output.
- **Reused temp filenames + deferred reads.** python-pptx may read at save time, so a temp name
  reused across example index leaves every slide embedding whichever file was written last.
- **`sorted(glob)[-1]`** picks a stale sibling if it sorts later. Check before adding a file next to
  one that is consumed this way.
- **A running Python process holds its code.** Editing a module cannot affect an in-flight render;
  restart it or accept the old behaviour.
- **The other window edits the same checkout.** Stage explicit paths, never `git add -A`. Two
  "flaky" test failures today were `conftest.py` changing underneath a running suite — different
  test each run, both passing in isolation.
- **`lesion_side('PS92')` iterates the STRING.** Pass a list. `stroke_laterality: "L"` is present
  for all four animals; an earlier claim that it raises was a malformed probe.
- **Windows delete-pending phantoms.** After `rm -rf` on a directory with an open handle, NTFS
  renames the entry to `.00000008…` and it lingers in listings while `ls`/`rmdir` say "No such
  file". Not corruption; it clears itself.
