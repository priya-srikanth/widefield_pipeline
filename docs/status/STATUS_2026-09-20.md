## 5. PITFALLS THAT BIT, 09-19 AND 09-20

- **At n=4, anything not visible in three animals individually will not survive.** Four striking
  numbers died this way. Two traps: a cell carried by ONE animal, and an animal with a SINGLE
  baseline session, where the bootstrap has nothing to resample so its uncertainty never enters
  the CI.
- **`fan_out` returns COMPLETION order.** Keying by label is not enough — bootstrap pools are built
  by iterating the collection, so a seeded RNG over a different order gives different draws. It
  moved a CI while leaving the point estimate exact. **Collect in sorted order.**
- **Spawn does not inherit runtime globals.** An option set as a module global in the parent
  silently does nothing in every worker while working perfectly in a serial run. Pass it in the item.
- **A control defined by the ABSENCE of a detection inherits every limitation of the detector.**
  Its purity must be measured, not assumed.
- **Threshold on LOCAL contrast, not absolute value.** A darkest-decile "vessel" mask selected the
  dim anterior edge. Same error as the colour-scale bug.
- **Per-panel autoscaling makes four epochs look identical.** Share y within a family; a rescaled
  flat line looks like structure.
- **Moving a window to escape one confound can walk into another** — the late window escaped
  bleed-through and met the denominator's epoch-dependent decay.
- **Check the output directory before asserting what the deck renders.** I claimed no map family
  did tested epoch deltas; `epoch_15r_position_RESTWref_*` has had them all along.
