# CIs for 34's early frozen-encoder tables (2026-11-05, a8)

Inputs: copies of 34's `b12_sessions.csv`, `per_session_class.csv` and `per_session_class_nospont.csv` in
`M:/MICROSCOPE/Priya/Widefield/labcams/decoder_mix_checks/frozen_b12_cis_1105/inputs/`. Outputs:
`cis_summary.csv` and `cis_log.txt` (per-animal tables printed first) in the same folder. Script: a8 scratchpad
`frozen_cis/cis.py`. Read-only; no repo code changed. Conclusions go to Priya before any page or deck text changes.

Two tests per change vs pre:

- `boot_delta` is the animal-weighted paired nested bootstrap (95 % interval).
- `epoch_change_lmm` is the session-row mixed model with t on df = animals - 1. It is the test the figures' stars use.

At n = 4 the two can disagree. Where they do, the bootstrap interval excludes 0 but the mixed model does not reach p < .05.

- PS95's late chronic value is partly the pre-stroke lick kernels over-predicting lick-heavy sessions.
