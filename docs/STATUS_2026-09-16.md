## 2. THE SCIENCE, AT ITS ACTUAL STRENGTH

**REST CARRIES POSITION** — 1.634 observed/null, 43/44 sessions, 4/4 animals, and 94/96 sessions
decode above their own circular-shift null. This is the solid one.

**THE REST CODE IS PARTLY REPLACED, NOT RECOVERED** (`15f`). Chronically the within-session refit
reaches 1.181 of its own pre-stroke level while the frozen pre-stroke model reaches 0.611: position
is in chronic rest, read by something other than the pre-stroke code. The refit arm is paired on the
SAME periods, so the only difference between the arms is the estimator.

**THE REST POSITION CODE IS NOT THE TASK POSITION CODE.** `15s` finds the task map and that
position's own rest map close to unrelated — cosine **0.09 post-cue, 0.16 pre-cue**. Both facts hold
together: rest carries position, in a largely DIFFERENT spatial code. Consistent with 15f's
confusions, where far-contra REST holds up (0.50 → 0.38 → 0.39) while far-contra TASK collapses
(1.46 → 0.47).

**THE PRE-CUE SIGNAL CARRIES A BACKWARD-POINTING TRACE.** `15s`: the pre-cue window shares
position-specific structure with rest (+0.060 pre, +0.188 acute, 4/4 animals) and the post-cue
window does not (flat against its null at every epoch). The block-boundary test says which way that
shared component points — rest resembles **the position just licked at**, not the one coming next
(+0.0772, 4/4). So the pre-cue signal carries a trace of the LAST target rather than preparation for
the next: **a real constraint on reading it as anticipatory**, and consistent with this project's
standing refusal to call it "a maintained motor plan".

**THE FOUR WINDOWS ARE NOT INTERCHANGEABLE** (`PRELIM_DATA` §5b). Pre-stroke information rises
toward movement — far-contra accuracy **ENL 0.507 · CUE 0.896 · LICK 0.952**. The LICK window's
apparent acute resilience (0.42 retained vs CUE's 0.21) is **SELECTION**: it conditions on a
detected lick and acutely there are only **64 far-contra lick trials**. Chronically CUE and LICK
recover their template match to ~1.000 while **ENL does not — and the positions that fail are
near-middle (0.111), far-ipsi and far-middle (0.444), NOT far-contra (0.889)**. The anticipatory
representation that never returns is not the lesioned one.

**THE COMPOSITION BIAS GROWS POST-STROKE** (`epoch_15d`): **2.56× chronic vs pre**, 3/3 animals with
chronic data. `restw` is correct AND load-bearing — the 200-frame floor and column-drop machinery
are warranted, not overhead.

**ACUTE ERRORS COLLAPSE, THEY DO NOT SCATTER** (15f confusions). Acute predictions pile onto
near-contra and far-row errors shift toward near columns (0.56 → 0.67). The rest code SHIFTS rather
than simply degrading.

  was overstated twice before landing there (first raw values the null eats, then a 0.065 residual

* **`15s` SUBACUTE IS PS92 ALONE** (−0.639 against +0.212, +0.044, +0.027). Exclude subacute.

## 3. WHAT THE AUDIT FOUND (full record: `docs/REST_ENGAGEMENT_AUDIT.md`)

**DEFECT 1 — a documented gate that was never implemented.** Four rest analyses stated a
working-trials gate in their docstrings; `rest_position_decode` printed "(working trials…)" in its
own stdout header. The only filter applied was that the bracketing trials agree on POSITION. The
quit period is **3.1% of rest frames pre-stroke and 18.7% acute**, so the contaminant tracked the
independent variable.

**DEFECT 2 — the raw classifier.** PS92/PS93/PS94/PS95_0806 — one PRE-STROKE session per animal —
collapse from six positions to four under `_classify_cues`, 144–192 trials mislabelled each.
**Fourth recorded occurrence** of the defect pitfall 6 already names.

**DEFECT 3, introduced WHILE FIXING the other two** — a patch snippet referencing `a` as an argparse
namespace where it was the rest-bout loop variable. Caught by `ruff F821` before it ran.

All three spread the same way: scripts written from each other as templates, copying prose and
structure together.

**CORRECTLY UNGATED, LEFT ALONE:** the mask builders (the animal IS at rest; gating there would
redefine the mask and force the whole recompute + schema + cache cascade for what is an inclusion
criterion), quiet-vs-running in preprocessing (**the imaging box needed no re-run**), and
`locomotor_state`, where rest is a CLASS being decoded rather than a baseline.

**ALREADY CLEAN:** `_RESTWref_` and the encoder's `_restw_baseline` — gated since 2026-09-14 via
`rest_frames_by_position(engaged_only=True)`. An earlier draft of the audit claimed otherwise; that
was a file-level check too coarse to see one gated builder and one ungated one in the same module.

**`_quiet_zscore` RESOLVED, no action** — SD unchanged (1.0000), mean shifts 0.033 σ in
acute/subacute only, absorbed by every consumer, and the frozen decoder never reads that path.

## 5. PITFALLS FROM TODAY

   each builds the gate AND uses the repaired classifier.
2. **TEMPLATING SPREADS DEFECTS WITH STRUCTURE.** All three defects propagated by writing scripts
   from siblings. When you copy a collection loop, copy its GUARDS or delete its claims.
3. **A PARTIAL COHORT IS NOT A TREND.** A 4-of-44 smoke gave 1.469 and was read as "the direction is
   down". The cohort came in at 1.634 — UP. Same trap `CLAUDE.md` documents for render timings,

   were described as fixed for both defects when they had only the classifier fix — the patch script
   had reported success for a different change. **Count call sites.**

   up as "frozen minus refit" and every post-stroke cell read backwards. Take a sign from the
   `_meta.csv` `ylabel` or the code, never from memory.
6. **CHECK FOR AN EXISTING CONTROL FAMILY BEFORE DEFERRING A RESULT.** The task arm's training-set
   matched `5rm` already existed when the frozen-vs-refit result was deferred over "data poverty" —
   an objection that also pointed the wrong way.

8. **MEASURE THE INPUT, NOT EVERY CONSUMER.** `_quiet_zscore` was settled for all three of its
