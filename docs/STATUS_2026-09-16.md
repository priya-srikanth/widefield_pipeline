## 3. PITFALLS FROM THIS SESSION — read before repeating any of them

1. **A plateau is not completion.** Cache count sat flat at 708 and I said the shared copy was
   "likely current". It was a STAGE BOUNDARY: the render had moved to a stage that writes no cache.
   The published snapshot held only per-session decode kinds; the frozen/RSA/grant kinds were
   missing and the other box cold-recomputed them. **Publish at END of a render, or repeatedly.**
2. **A `CACHE_VERSION` bump is a TWO-MACHINE change.** Dev work happens on this box; nightlies run
   on the other. Bumping here invalidated its cache too. **Bump → publish the cache**, as one action.
3. **Benchmarks are for a job, not a name.** I quoted CLAUDE.md's 10 h 26 m — a WARM-cache nightly
   over ONE date — for a COLD-cache run over 36 dates with no skips. It took **27 h 12 m**. The repo

   figure the render flagged wasn't in the manifest map I queried.
5. **Pooled means hide reversals.** The acute-dip withdrawal. The composition test had ALREADY
   taught that between-animal replication beats a pooled mean, and I read a trajectory off a cohort
   average anyway. **Plot the animals before describing a trajectory.**
6. **"4 positions" is a classifier artefact, not an animal.** Third occurrence: a script written
   AFTER the `classify_cues_with_backup` fix used raw `_classify_cues`. Dead `spout_bit1` collapses
   6→4 (8/05–8/06 only). **When a session reports 4 positions, check the classifier first.**
7. **Stale text outlives the code it describes.** Fixed this session: the `restw` colourbar saying
   "time-local" (it is FLAT since 09-14), "differ ONLY in the weighting" (they differ on TWO axes),
   "fewer than four positions" (gate is SIX), a RUNTIME log printing `<4`, `--skip-grant`'s 8–10 h,
   and `rest_position_vs_drift` printing a RETIRED verdict. **Grep captions when an estimator moves.**
8. **A SIGN CONVENTION RESTATED IS A SIGN CONVENTION GUESSED.** I wrote the frozen-vs-refit gap
   up as "frozen minus refit" and read every post-stroke cell backwards -- reporting that a frozen
   pre-stroke decoder BEAT a same-day refit, when the figure's own `ylabel` says
   `refit - frozen accuracy` and `_gap_at` returns `refit - frozen`. `tests/test_frozen_vs_refit.py`
   has asserted the correct direction all along; the prose still went wrong because it restated the
   convention instead of reading it off the artefact. **Take a sign from the `_meta.csv` `ylabel`
   or the code, never from memory.**
9. **A caveat can point the wrong way.** From the inverted sign I deferred the result over "data
   poverty" -- but trial scarcity pushes the gap NEGATIVE, so it makes the observed POSITIVE gap
   harder to get, not easier. And the objection was already answered: the **`5rm` training-set
   MATCHED family** exists for exactly this (Priya, 2026-09-10). **Check for a control family
   before writing "interpretation not settled".**
10. **A NULL CAN BE EMPIRICAL AND STILL BE THE WRONG ONE.** The frozen rest decoder permuted 200
    labels per session -- not the analytic 1/6 -- but used `rest_position_decode`'s CIRCULAR SHIFT,
    whose docstring claims it "keeps blocks as blocks". MEASURED: with unequal block lengths (which
    real blocks have) a roll misaligns the boundaries and leaves only **~31%** of blocks internally
    constant, against **100%** for a block permutation and **~1%** for a trial shuffle. The shift
    sits between the two and the null is too weak. Three conventions exist here and they are NOT
    interchangeable: `decode_ci.frozen_ci` (block permutation, the FROZEN task decoders),
    `nolick_analysis.permutation_null` (trial shuffle, the per-session ENL/cue/lick decoders),
    `rest_position_decode` (circular shift). **Match the null to the estimator.**
11. **A BALANCED NULL AT 1/6 PROVES NOTHING.** Under a trial shuffle the balanced-accuracy null is
    ~1/ncls BY CONSTRUCTION -- balancing removes exactly the class skew the shuffle carries. So a
    null landing on chance is equally consistent with a working permutation and a useless one.
12. **"ABOVE NULL" IS NOT A TEST.** I reported 16/16 acute sessions above their null; that was
    `acc > null mean`. At p<0.05 under the right null it is 8/16. **Say which criterion.**
13. **CHECK FOR AN EXISTING CONTROL FAMILY BEFORE DEFERRING A RESULT.** Twice now: the task arm's

14. **`git commit -m` broke repeatedly.** Use `-F` with a file. Always.
