## 1. What this work is for

Two deliverables, one dataset. The science question is unchanged from 8/23:

    Pre-stroke you can read spout position out of pre-cue activity.
    After the lesion the animal fails at the contraversive positions.
    Is the position CODE still there and unread, or has it changed?

The **grant figure set** (`wfield_local/grant_figures.py` → `<labcams>/grant_figures/`) is a
self-contained answer to that for a progress report and a new application. It is deliberately
caveat-LIGHT for a non-specialist reader; the caveats live in the module docstrings, in DECISIONS.md,
and in the speaker notes of deck **section H**, which places every grant figure.

## 3. Findings worth not re-deriving

- **The far_R code MOVED; it did not merely get noisier.** Post-stroke far_R is measured as
  repeatably as ever (PS92 0.90–0.95 split-half against a pre-stroke 0.80) while its similarity to
  the pre-stroke pattern is ~0. Disattenuation barely moves it (fig 7b).
- **The control is not vacuous** — it catches `close_center`, whose reliability collapses to
  0.01–0.32 in three animals. **close_center's apparent change must not be quoted.**
- **The drop is GRADED, not far_R-exclusive.** All 27 animal-days have intervals excluding zero;
  far_R is largest in all four animals.
- **Trajectories differ by animal and the pooled figures hide it**: PS93 and PS94 recover, PS95
  worsens (−0.13 at d2 → −0.38 at d9), PS92 is flat.
- **Substitution**: post-stroke far_R activity moves toward pre-stroke close/central patterns —
  matching Priya's behavioural observation of incomplete leftward/central licks on far_R misses.
- **8b is the arbiter for anything about GEOMETRY.** It is gain-invariant; 6 and 8 are not. Fig 8
  puts PS92/PS93 at their worst on day 7 while 8b puts day 7 among their best — that spike is
  amplitude, not a code moving further away.
- **In 8d, a uniform row is amplitude, not resemblance.** `d(post P, pre Q)` contains a term in
  |mu_postP|² alone. 8f (row-centred) is the panel that answers "toward WHICH position".
- **8b's blank cells are an estimator threshold, not biology.** A row correlation needs 4 of its 5
  partners; PS94 d1/d2 have only 4 positions in the LICK class, so every row blanks. **The WORKING
  class has all six positions on every day for every animal — read that one.**

## 4. Method decisions that must not be silently reverted

- **Leave-one-session-out everywhere a pre-stroke baseline is compared to a post-stroke session.**
  Figures 6/6b/7/7b/8/8b/8d and section G's `r_pre_loo` were all corrected to this. A random split
  of pooled pre-stroke TRIALS puts both halves on the same days, carries no drift, and is a ceiling
  no across-day comparison can reach.
- **The ceiling is NOT 1.0.** Read post columns against the PRE column. PS94 post-cue disattenuates
  to 0.75–0.86 for an unchanged code.
- **Bootstrap: ~6-trial position BLOCKS resampled within session; SESSIONS HELD FIXED** (days are
  not exchangeable while an animal recovers). Bootstrap, not permutation, for asymmetry.
- **A standing check, from four instances in two days:** *whenever a baseline is computed, ask what
  is inside it.* Fig 6's half-split, 8b's ceiling, `_delta_diag_ci`'s `mats_fn(ref, ref)`, and the
  frozen models training on post-stroke sessions were all the same shape.

## 7. Recurring hazards in this codebase

- **Heredocs mangle `\n`.** Writing `\\n` inside a quoted bash heredoc has produced a REAL newline
  four times, splitting f-strings mid-literal. Use the Edit tool for anything containing escapes, or
  build the escape as `chr(92) + "n"`.
- **A mechanical sweep over a file rewrites its own helper.** Routing every `fig.suptitle(` and every
  `fig.savefig(` through a wrapper rewrote the wrapper's own call into a recursive one — twice. Both
  now use the explicit unbound form (`Figure.suptitle`, `Figure.savefig`).
- **A repair heuristic loose enough to fix an unknown break is loose enough to cause one.** A script
  keyed on "odd number of quotes on consecutive lines" silently rejoined 23 comment lines; the file
  had to be reverted.
- **Replicas lie.** Two synthetic reproductions of a layout fault reported clean while the shipped
  figure was visibly wrong (one omitted the colour bar). Drive the REAL drawing function with
  fabricated data instead — `_draw_5c` takes only `(per_animal, days, out_dir, align, wname)`.
- **`await_locanmf` registers sessions continuously**, so a long render freezes the session list at
  its start. Three sessions landed mid-work in two days. `coverage_note` stamps what each figure's
  own source contained, which reports staleness rather than preventing it.
